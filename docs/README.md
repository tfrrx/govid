## 维护约定

1. **需求变了** → 改 `01-需求分析文档.md`，并在 §7 变更记录追加一行，**不要覆盖旧行**。
2. **架构变了** → 改 `02-技术架构文档.md`，踩坑记录只增不删（避免后人踩回同一个坑）。
3. **平台可用性变了** → 更新 `03-平台支持矩阵.md` 的实测表并改实测日期。
4. 文档里写的结构/字段/行为，必须能在代码里找到对应。**禁止写设想中的架构**。
